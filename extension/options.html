About

UWAL adds a universal action layer to any website. Use the floating toolbar or the smart selection menu to save objects, extract structured data, compare items, annotate, track changes, and summarize content.

  • Alt+UToggle the floating toolbar
  • Alt+SSave the current page
  • Alt+PPick an element to act on
